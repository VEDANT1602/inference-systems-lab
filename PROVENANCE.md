# Source and measurement provenance

This repository is the standalone form of Vedant Thaker's `projects/inference-systems-lab` project in the [Applied AI and Decision Systems portfolio](https://github.com/VEDANT1602/DataScienceProject). The original portfolio records AI implementation assistance in its [provenance statement](https://github.com/VEDANT1602/DataScienceProject/blob/ef9c14c01163ad3eadb3eaa673c0073b14478184/docs/provenance.md).

The source snapshot is commit [`ef9c14c01163ad3eadb3eaa673c0073b14478184`](https://github.com/VEDANT1602/DataScienceProject/tree/ef9c14c01163ad3eadb3eaa673c0073b14478184/projects/inference-systems-lab). The project history was extracted with `git subtree split` in an isolated local clone. Filtered commits retain their original author, timestamp and message; their commit IDs change because the parent history and tree paths change. The extraction does not change the source portfolio or its history.

The extracted tree was verified as `4f509aa328caea8bc46f6fece582d62a2209241f`, identical to the project's tree at the source commit before packaging. [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) records the original file blobs, filtered head and source tree. Packaging adds this statement, standalone CI and a link from the README, while retaining existing project ignores. Runtime code, fixtures, data contracts and recorded experimental outputs remain unchanged.

The numerical results retain their original dates, datasets, environment and limits. Unit tests validate the standalone checkout; extraction is not a new benchmark or a new employer deployment. Employer and customer code/data are not included. Dataset and conceptual-reference terms remain those documented in the original project.

The free Colab Tesla T4 artifacts continue to identify original source commit `5780a7c0661c4cf528957cff730de16e3fd447c4`. The notebook and its builder deliberately retain the original portfolio sparse-checkout URL. That is the source used for the recorded hardware check; this standalone extraction was not newly benchmarked. The measured workload is tiny attention arithmetic, not an LLM serving test. vLLM serving, Nebius and Nsight measurements remain unexecuted.
